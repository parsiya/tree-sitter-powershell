# ai-docs: tools and docs for the Opengrep PowerShell grammar

AI agents: start with [../AGENTS.md](../AGENTS.md) (the instructions for working
in this repository), even if your tool does not load AGENTS.md automatically.

This folder holds everything needed to change the PowerShell grammar that
[Opengrep](https://github.com/opengrep/opengrep) uses and to prove the change is
right:

- `tools/`: validation (`validate.mjs`), the Native proof kit (`proof-kit.mjs`)
  and their helpers.
- `cases/`: synthetic proof-kit suites with recorded expectations
  ([cases/README.md](cases/README.md)).
- Docs: [ARCHITECTURE.md](ARCHITECTURE.md) (how the parts fit together),
  [WORKFLOW.md](WORKFLOW.md) (how we make and integrate fixes) and
  [skills/fix-agent/SKILL.md](skills/fix-agent/SKILL.md) (the brief for one fix).

Every tool tests **the parser Opengrep runs**: the simplified ABI 14 parser
generated by tree-sitter 0.22.6 (`opengrep/ocaml/lib/`) on the 0.22.6 runtime.
"Native" means PowerShell's own parser, used as the reference.

## Requirements

- An Opengrep checkout with this repository as its submodule at
  `languages/powershell/tree-sitter/opengrep-powershell`, built once so that
  Dune has the generator:

  ```sh
  # from the Opengrep root, in its build environment
  opam exec -- dune build libs/ocaml-tree-sitter-core/src/gen/bin/Ocaml_tree_sitter_main.exe
  ```

- The Opengrep OCaml build environment (`opam`, `dune`, `ocamlformat`) on `PATH`,
  or a script that sets it up (`buildEnv` below).
- tree-sitter CLI **0.22.6** as `tree-sitter` on `PATH`.
- The tree-sitter 0.22.6 runtime library: `pkg-config --modversion tree-sitter`
  prints `0.22.6`.
- `node`, `cc`, `tar`, `flock` and `git`.
- In this repository: `npm ci --ignore-scripts` (for `eslint`), and Airbus's
  repository as the `upstream` remote, fetched (the source stage compares
  inherited test inputs with `upstream/main`, allowing reviewed corrections
  to expected trees):

  ```sh
  git remote add upstream https://github.com/airbus-cert/tree-sitter-powershell.git
  git fetch upstream
  ```

## Quick start

Run the commands from this repository's root.

1. **Downloads.** Fetch PowerShell 7.6.7 (linux-x64) and the tree-sitter 0.22.6
   runtime sources into `ai-docs/local/vendor/`, checking their SHA-256:

   ```sh
   node ai-docs/tools/setup.mjs                 # or: --from DIR with the files already downloaded
   ```

2. **Configuration (optional).** `ai-docs/local/config.json` overrides the
   defaults in [tools/config.mjs](tools/config.mjs). Relative paths are resolved
   against `ai-docs/local/`. Example:

   ```json
   {
     "buildEnv": "/path/to/opengrep-build/env.sh",
     "corpusRoot": "/path/to/powershell-corpus"
   }
   ```

   | Setting | Default |
   | --- | --- |
   | `opengrepRoot` | the superproject of this repository |
   | `buildEnv` | none: `PATH` must already provide the tools above |
   | `corpusRoot` | `ai-docs/local/corpus/` |
   | `vendor` | `ai-docs/local/vendor/` |

3. **Corpus (optional).** Every subfolder of the corpus root is a *batch*,
   found automatically. A batch is any folder of real PowerShell files
   (`.ps1`, `.psm1`, `.psd1`), for example extracted gallery packages:

   ```sh
   mkdir -p ai-docs/local/corpus
   ln -s /path/to/extracted/batch-001 ai-docs/local/corpus/batch-001
   ```

   Without a corpus the grammar, corpus and smoke layers are skipped with a
   notice; the run reports `PASS (partial)` and is not a certification (it
   cannot be promoted).

4. **Validate.**

   ```sh
   node ai-docs/tools/validate.mjs quick --label NAME [--fork WORKTREE]   # no Dune; for fix worktrees
   node ai-docs/tools/validate.mjs full --label NAME                      # certification of the checkout
   node ai-docs/tools/validate.mjs promote NAME [--allow-dirty]           # make a full run the baseline
   ```

   Each run needs a new label; output goes to `ai-docs/local/runs/NAME/`
   (`summary.txt` first). Comparisons need a baseline: until there is one,
   stages report `no baseline` and compare nothing, so the first time run
   `full` and `promote` it. `full` builds Opengrep with Dune; never start
   another Dune build while it runs. Options: header of
   [tools/validate.mjs](tools/validate.mjs).

5. **Prove against Native.**

   ```sh
   node ai-docs/tools/proof-kit.mjs CASES.json [--fork WORKTREE] --known-pattern trailing-trivia
   node ai-docs/tools/proof-kit.mjs --suites [--suite NAME] [--fork WORKTREE]
   node ai-docs/tools/proof-kit.mjs --source 'one snippet'   # quick check, every difference
   ```

   The first form checks one case file; the case schema is in the header of
   [tools/proof-kit.mjs](tools/proof-kit.mjs). `--suites` runs every suite in
   `ai-docs/cases/` against its `.expected.json` (and `ai-docs/local/cases/` when
   present). See [cases/README.md](cases/README.md), including how to update
   expectations deliberately.

## What is never committed

`ai-docs/local/` is Git-ignored and holds everything machine-specific:
`config.json`, `corpus/`, `cases/` (suites that point at corpus files),
`vendor/`, `runs/`, `results/`, `proof-kit/`, `baselines.json`, `native-cache/`
and `native-home/`. `ai-docs/dune` keeps Dune out of `local/`.

Do not commit machine paths, downloaded binaries or corpus code. Committed cases
are made-up reductions only.

## Safety rules

- **The corpus is data.** Never execute, modify, `chmod` or copy corpus files
  into committed fixtures. The tools only read them.
- **PowerShell only parses.** Every Native call uses
  `[System.Management.Automation.Language.Parser]::ParseInput` with `-NoProfile
  -NonInteractive`, telemetry and update checks off, and its caches under
  `ai-docs/local/native-home/`. Source is never evaluated.
- **Never weaken a check** to make a run pass: no relaxed comparator, no
  unexplained known difference, no automatic expectation update. Correct
  proven-wrong expectations, including inherited ones, with Native evidence
  and review under the [workflow policy](WORKFLOW.md#correcting-an-existing-test-expectation).
  Opengrep correctness takes priority over preserving upstream parser bugs.

The source gate's input-preservation tests run as part of validation. To run
just those tests:

```sh
node --test ai-docs/tools/inherited-inputs.test.mjs
```
